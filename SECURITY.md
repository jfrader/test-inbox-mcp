# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Contact the repository owner privately using the security contact configured on the repository hosting service.

Include the affected version, reproduction steps, impact, and any suggested mitigation. The maintainer will acknowledge the report and coordinate disclosure after a fix is available.

## Deployment scope

This project handles test email that may contain login links, one-time codes, and personal data. Do not use it as a mailbox for production users. Protect the HTTP API, keep retention short, and restrict access to the MCP process and its credentials.
